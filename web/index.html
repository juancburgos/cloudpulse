🧭 ¿Qué es CloudPulse?

CloudPulse es una app Android sencilla a propósito, construida como pieza de portafolio para demostrar una arquitectura de producción completa. Desde el teléfono hace ping a su propia API (que vive en un VPS real), la API escribe en PostgreSQL y devuelve el estado del sistema. Sirve para explicar, componente por componente, cómo se monta y opera un servicio en la nube.

🏗️ Arquitectura

┌────────────┐   HTTPS/TLS   ┌───────────┐   HTTP   ┌─────────────┐    SQL    ┌──────────────┐
│  App       │ ────────────► │  Caddy    │ ──────►  │  API        │ ────────► │  PostgreSQL  │
│  Android   │               │ (proxy +  │          │  FastAPI     │           │  (Docker,    │
│  (Kotlin)  │               │  certs)   │          │  (Docker)    │           │   volumen)   │
└────────────┘               └───────────┘          └─────────────┘           └──────────────┘
      │                            │                       │                        │
      └── /api/v1/status, /api/v1/ping (POST)             healthz                   volumen
  • Cliente: app Android nativa (Kotlin, Material 3) con manejo de errores y reintento.
  • Edge: Caddy — terminación TLS automática (Let's Encrypt), reverse proxy.
  • Aplicación: FastAPI (Python) en contenedor Docker, endpoints /healthz, /api/v1/status, POST /api/v1/ping.
  • Datos: PostgreSQL 16 en contenedor con volumen persistente; healthcheck del contenedor.
  • Operación: docker compose para desplegar/re-desplegar; configuración 100% portable a cualquier VPS.
  • Observabilidad: endpoint de salud + estado en vivo (este sitio lo consulta).

📲 La app

CloudPulse está publicada en Google Play (enlace abajo). Muestra tarjetas de estado en vivo, un botón “Enviar ping” que escribe en la base de datos y un historial de pings — todo contra la API real.
