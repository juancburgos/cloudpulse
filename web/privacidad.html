Política de privacidad — CloudPulse

Última actualización: 9 de septiembre de 2026

Resumen: CloudPulse es una aplicación de demostración/portafolio. No recopila, almacena ni comparte ningún dato personal.

1. Qué hace la aplicación

CloudPulse muestra el estado operativo de su propia API de demostración y permite enviar un "ping" (un contador con marca de tiempo) que se guarda en una base de datos. La aplicación no requiere crear cuenta, no pide nombre, correo, ubicación ni contactos, y no muestra publicidad.

2. Datos que se procesan

Cuando usas la aplicación, se envía una petición HTTPS a la API. El servidor guarda únicamente datos técnicos no personales del ping: la fecha/hora y una cadena corta de identificación del cliente (cabecera User-Agent del dispositivo), usada solo para depuración. No se recopila información que permita identificarte.

3. Almacenamiento

Los registros de ping se almacenan en una base de datos PostgreSQL del proveedor de nube que aloja la API, exclusivamente con fines de demostración técnica. Pueden borrarse en cualquier momento sin afectar el funcionamiento de la aplicación.

4. Permisos

La aplicación solo necesita acceso a Internet. No solicita ningún otro permiso del dispositivo.

5. Servicios de terceros

No se usan analíticas, anuncios ni SDK de terceros que recopilen datos.
