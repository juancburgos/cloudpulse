## ⏳ Pasos restantes para PRODUCCIÓN (requisito de Google para cuentas nuevas)

1. **Esperar la aprobación de Google del closed test** (1–7 días; ver "Changes in review" en Publishing overview).
2. **Que los testers acepten el opt-in** del closed testing (abren el enlace con su cuenta Google y aceptan).
3. **Al menos 12 testers** deben estar "opted-in" en el closed test. La lista actual tiene 3 correos del propio
   usuario → agregar ~9+ correos reales más (amigos/colegas/segundo celular). Se agregan en
   Consola → app → Testing → Closed testing → Testers → "CloudPulse team" → Editar (misma pantalla de
   "Create email list", separar con comas y Enter). Opcional: subir un CSV.
4. **Esperar 14 días corridos** desde que el release cerrado está aprobado/publicado.
5. **Aplicar para acceso a producción**: Dashboard → "Apply for production" → responder el formulario
   (describe: app demo de portafolio, ~12 testers, 14+ días) → Google revisa (horas a ~7 días).
6. (Cuenta) **Verificación de identidad del desarrollador**: revisar en Consola → "Android developer
   verification" — si está pendiente, completar con documento de identidad (el propio usuario).

> Nota: mientras tanto la app ya es instalable vía internal testing y el closed testing (los enlaces aparecen
